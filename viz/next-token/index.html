LLM은 어떻게 다음 단어를 고를까?

챗봇은 문장을 통째로 생각해내지 않습니다. 다음에 올 단어 하나를 확률로 고르고, 그걸 문장 뒤에 붙인 다음, 다시 처음부터 반복할 뿐입니다.

확률 룰렛 — 막대 너비만큼 자리를 차지하고, 바늘이 떨어진 칸의 단어가 뽑힙니다
자세히 — 온도는 무엇을 바꾸는가

모델이 내놓는 건 확률이 아니라 로짓이라는 점수 $z_i$ 입니다. 이 점수를 확률로 바꾸는 계산이 softmax이고, 온도 $T$ 는 여기 들어갑니다.

$$p_i = \frac{e^{z_i / T}}{\sum_j e^{z_j / T}}$$

$T$ 가 작으면 1등 점수만 살아남아 확률이 한쪽으로 쏠리고(항상 같은 답), $T$ 가 크면 점수 차이가 뭉개져서 낮은 확률의 단어도 자주 뽑힙니다(엉뚱한 답). 위 슬라이더는 이 식을 실제로 다시 계산합니다.
